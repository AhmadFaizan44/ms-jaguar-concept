# MS Jaguar landing page concept

A concept landing page for MS Jaguar's electric scooters and bikes. **Not an official MS Jaguar site.** Specs, prices and photos come from msjaguarmotorcycles.com.

Built with Next.js, Tailwind CSS, Motion and Lenis. The site lives in `web/`.

```bash
cd web
npm install
npm run dev
```

Every push to `main` publishes the site to GitHub Pages.
